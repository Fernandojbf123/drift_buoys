El módulo procesado_datos cuenta con dos submódulos:

- despliegue:
    Este módulo se encarga de crear todos los archivos necesarios para realizar los reportes de despliegue.
    Entre los archivos se incluye:

    - datos crudos de las pruebas de laboratorio
    - grafico de serie de tiempo de voltaje con las horas de laboratorio
    - mapa de posición durante las pruebas de laboratorio
    - mapa con las posiciones de despliegue
